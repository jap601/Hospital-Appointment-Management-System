# Hospital-Appointment-Management-System
Hospital Appointment Management System

Project Description

The Hospital Appointment Management System is a web-based project developed to make the appointment booking process easier for patients. Patients can enter their details, select a doctor, choose an appointment date, and book an appointment.

Technologies Used

- HTML
- CSS
- JavaScript

Features

- Patient appointment booking
- Patient details form
- Doctor selection
- Appointment date selection
- Search appointments
- Delete appointments
- Form validation
- Display appointment records

OOP Concepts Used

- Class and Object: Used to organize patient and appointment details.
- Constructor: Used to initialize object properties.
- Inheritance: Patient and SpecialistAppointment classes inherit from parent classes.
- Encapsulation: Data and related methods are organized inside classes.
- Polymorphism: The getType() method is overridden in the specialist appointment class.

How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open the "index.html" file in a web browser.
4. Use the form to book an appointment.

Project Limitation

Appointment records are stored temporarily in JavaScript. They are not saved permanently in a database.

Future Scope

- Add a database for permanent storage.
- Add patient login and registration.
- Add an admin dashboard.
- Add online appointment confirmation.
